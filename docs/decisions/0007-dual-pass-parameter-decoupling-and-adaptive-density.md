# ADR 0007: 双轮生成管线参数解耦与自适应密度

- **状态**: Accepted
- **日期**: 2026-09-24
- **决定者**: 架构与算法核心

---

## 1. 背景与问题 (Context)

在早期的双轮生成管线中，用户指定的配置参数（例如特定复古硬件调色板如 Game Boy、1-bit 黑白、极低密度 8/16 等）是全局直接贯穿至首轮模型调用的：
1. **首轮语义塌陷**：当用户选择极严苛的调色板（如 4 色 Game Boy）或极小像素密度时，原图在 Pass 1 生成 reference guide 时就丢失了大量色彩层次与五官细节，导致大模型在首轮构图时产生误判或结构崩坏。
2. **两轮职责混杂**：Pass 1 需要同时承担「理解自然图构图」与「强行落地受限色板」，增加了大模型的幻觉与画崩概率。

---

## 2. 决策内容 (Decision)

将双轮生成流程的参数控制彻底解耦为两个阶段：

### 2.1 Pass 1：语义构图与高保真草稿
- **调色板**：固定采用 `Auto` 调色板（基于 Oklab 空间的 K-Means 自动聚类），全量保留原图的明暗与色彩梯度。
- **像素密度**：根据原图分辨率长边 $\max(W, H)$ 执行 **5 档全覆盖自适应映射**（`adaptive_density_for_source`）：
  - $\ge 2560\text{px}$ (4K / 超高清) $\to$ **128** 密度
  - $1024\text{px} \sim 2559\text{px}$ (1080p / 2K) $\to$ **64** 密度
  - $384\text{px} \sim 1023\text{px}$ (典型 512×512) $\to$ **32** 密度
  - $128\text{px} \sim 383\text{px}$ (典型 256×256) $\to$ **16** 密度
  - $< 128\text{px}$ (极小微缩图 / 图标) $\to$ **8** 密度
- **目标**：为大模型提供最佳特征保真度的参考 guide，产出构图准确、结构完备的高清像素草稿。

### 2.2 Pass 2：目标风格收敛与点阵精修
- **目标参数生效**：将 Pass 1 输出按照**用户选择的目标调色板与目标密度**进行 Reducer 降采样，放大为 Review 图送入 Pass 2。
- **精修提示词**：让模型在用户指定的目标色板与网格密度下，专注进行边缘梳理、孤立像素合并与点阵精修。

### 2.3 单轮与本地模式直接直通
- 当用户选择单轮生成（`passes == 1`）或纯本地像素化（`pixelize_only`）时，用户选择的参数直接生效。

---

## 3. 产生的影响与收益 (Consequences)

### 正面收益
1. **防止首轮结构塌陷**：无论用户选择何种极端色板或分辨率，Pass 1 均能基于高保真信息生成结构正确的草稿。
2. **可视化体验极大增强**：左侧卡片直接输出 Pass 1 的自适应参考 Guide，让用户对模型输入的参考基准一目了然。
3. **Repixelize 体验极大增强**：首轮生成的 Raw 图保留了完整色彩先验，用户后续在前端重选色板或切换分辨率时，底图可用信息更充足。
4. **容错机制保持鲁棒**：若 Pass 2 超时或失败，回退机制会将 Pass 1 的高清 Raw 依用户参数降采样后返回，同样完全符合调色板闭包不变量。

### 遵循的不变量
- 无论双轮如何流转，最终输出严格受调色板闭包不变量断言保护（`assert_palette_subset`）。
