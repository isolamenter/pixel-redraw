# 3. 采用 Oklab 感知色彩空间与 QVote 网格量化

- **状态**: Accepted
- **日期**: 2026-09-23 (从重构设计文档及 `pixel_reduce.py` 提交确认)
- **决定者**: 核心算法设计

## 背景与问题

早期像素化方案直接使用传统图像插值缩放（如 Box / Nearest）配合 sRGB 欧氏距离颜色量化，在 AI 生成图转换为像素画时存在以下质量缺陷：
1. **混色污染与边缘模糊**：传统缩放对网格单元内像素做 RGB 均值混合，生成原图不存在的过渡色，导致硬轮廓被平滑成杂色带。
2. **感知失真**：sRGB 空间的欧氏距离在亮度和色度敏感度上与人眼不匹配，自动调色板提取和最近色匹配容易丢失关键高光或阴影细节。
3. **网格错位与孤立杂点**：AI 生成图片带有微小抗锯齿，如果采样相位不对齐，容易产生断线、孤立杂点（Orphan pixels）和单像素孔洞（Holes）。

## 决策

1. **色彩空间升级为 Oklab**：
   - 算法中所有色差度量与 K-Means 聚类全部在 Oklab 感知色彩空间下进行。
   - 保证自动调色板提取和最近色映射与人眼视觉感知一致。
2. **引入 Quantize-then-Vote (QVote) 网格量化**：
   - 先将每个采样单元内的高分辨率像素量化为调色板颜色，再以众数投票（Mode Vote）决定该网格单元的最终颜色。
   - 完全避免 RGB 均值插值产生的脏色，保留清晰硬边。
3. **网格相位微移对齐 (Grid Phase Alignment)**：
   - 在 $[-0.5, +0.5]$ 单元范围内搜索边缘梯度对比度最高的相位偏移，使网格边界精准切齐主轮廓。
4. **置信度感知拓扑清理 (Confidence-Aware Topology Cleanup)**：
   - 基于 QVote 得票率计算置信度，对低置信度孤立像素和单像素孔洞进行清理，同时保护高置信度细节（如眼睛、高光点）。
5. **轻量依赖约束**：
   - 所有算法仅依赖 NumPy 向量化与 Pillow 基础图像操作，不引入 OpenCV、scikit-image 或 scikit-learn 等重型依赖，确保在 Pyodide WASM 中轻快运行。

## 结果与影响

### 正面影响
- 像素画轮廓边缘清晰硬朗，不再产生插值伪影。
- 调色板映射和色彩提取显著更符合人眼审美。
- 算法完全确定性，经测试在 CPython 与 WASM 环境下逐位一致。

### 负面影响 / 权衡
- 在高密度（如 256x256 / 512x512）与超大调色板下，Oklab 转换和矩阵距离计算有一定 CPU 开销（已通过 NumPy 向量化优化）。
